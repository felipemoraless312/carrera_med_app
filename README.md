# Carrera por el Día del Médico

Aplicación web desarrollada para gestionar las inscripciones y la administración de participantes de la Carrera por el Día del Médico. El sistema permite registrar corredores, generar folios y comprobantes digitales con códigos QR, consultar participantes y controlar la asistencia, facilitando la organización y el seguimiento del evento.

**Tecnologías:** Python, FastAPI, JavaScript y SQLite.

**Objetivo:** Digitalizar y optimizar el proceso de registro y control de participantes mediante una plataforma accesible, eficiente y centralizada.
